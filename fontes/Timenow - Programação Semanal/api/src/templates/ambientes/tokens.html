Emitir token

O token entrega o histórico inteiro do cliente, de uma vez. Sem recorte por empresa contratada — não há pessoa atrás da credencial — e sem recorte por período: quem tem o valor lê todas as semanas numa chamada só. Emitir um token é, na prática, publicar a base daquele cliente inteira para quem o tiver.
Para saber qual integração usa qual token.
Em branco, o token não expira sozinho.
